<h1>小江投球公式可视化</h1>
<h2>一个基于理想条件下的投篮模拟器</h2>
<h3>
公式:
$$Ft = mS\sqrt{\dfrac{g}{S\sin 2x - h(\cos 2x + 1)}}$$

**适用条件**：h ≥ 0 时，0° < x < 90° 且 tanx ≥ 2h/S；h < 0 时，0° ≤ x < 90°

| 符号 | 含义 |
|---|---|
| m | 球的质量（kg） |
| t | 作用球的时间（s，选填） |
| F | 作用球的恒力（N） |
| x | F 与水平方向的夹角（°） |
| S | 球与框的水平距离（m） |
| h | 球与框的高度差（m），框高于球为正 |
| g | 重力加速度（m/s²） |

模型假设：忽略空气阻力与球自转，球与框视为质点，向上为正方向
</h3>
